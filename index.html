Miyoo Mini Ports

Native game ports for the Miyoo Mini, Mini Plus, and Mini Flip (SigmaStar SSD202D) that aren't in OnionUI/Ports-Collection. Each entry links to the port's own releases, so versions are always the author's latest.

Each port ships its own package; this site only links out. Most releases drop a Roms/ folder on your SD card, then you run ~Import ports in Onion's Ports list. Ports that need owned data stay hidden until that data is present.

Miyoo Flip (RK3566) and Miyoo A30 are different devices and not listed here. Source and contributing on GitHub.
